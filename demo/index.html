Engine loading — the fitter Go binary is compiled to WebAssembly (~7 MB gzipped), first load takes a moment…
Every run executes the real fitter engine — the same code as the CLI and MCP server — entirely client-side. Live HTTP examples use CORS-friendly public APIs (GitHub, OpenLibrary, CoinGecko); arbitrary page scraping and the browser/docker connectors need the native binary. Get it via go install github.com/PxyUp/fitter/cmd/fitter_cli@latest or the MCP server from the README.
