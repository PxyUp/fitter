Every run executes the real fitter engine — the same code as the CLI and MCP server — entirely client-side, compiled to WebAssembly (~7 MB gzipped, loaded once and cached). Live HTTP examples use CORS-friendly public APIs (GitHub, OpenLibrary, CoinGecko, Hacker News Algolia, httpbin); arbitrary page scraping and the browser/docker connectors need the native binary. Get it via go install github.com/PxyUp/fitter/cmd/fitter_cli@latest or the MCP server from the README.
